# PyTorch 기반 수량 인식 인공신경망 실험

## 1. 프로젝트 소개

PyTorch로 32×32 흑백 이미지에 그려진 점 개수를 분류하는 MLP 모델을 구현하고, 학습 조건에 따른 성능 변화를 분석하는 입문형 머신러닝 실험입니다.

## 2. 프로젝트 목표

- Python을 활용한 이미지 데이터셋 생성
- PyTorch 기반 MLP 모델 설계 및 학습
- 모델의 분류 정확도 평가
- 점 크기 변화에 따른 일반화 성능 분석
- 조건에 따라 달라지는 결과 비교

## 3. 기술 스택

- Python
- NumPy
- PyTorch
- Matplotlib
- Google Colab

## 4. 문제와 데이터

모델은 이미지에 그려진 점의 개수를 1~8 중 하나로 분류한다.

- 이미지 크기: 32×32 흑백
- 픽셀 값: 검정 0, 흰색 1
- 점 중심: 4×4 격자의 16개 후보 위치 중 서로 다른 위치를 선택하고, 중심에 ±1픽셀 흔들림 적용
- 기준 점 반지름: 2픽셀
- 기준 훈련 데이터: 점 개수별 400장, 총 3,200장
- 시험 데이터: 점 개수별 100장, 총 800장
- 라벨: 점 개수 1~8을 내부적으로 클래스 번호 0~7로 저장

점 위치가 4×4 격자 주변으로 제한되어 있어 실제 이미지 인식이나 사람의 수량 인지에 대한 결론을 내리는 실험은 아니다.

## 5. 모델 구성

- 입력: 32×32 흑백 이미지
- 모델: MLP (1024 → 128 → 64 → 8)
- 활성화 함수: ReLU
- 손실 함수: CrossEntropyLoss
- 옵티마이저: Adam
- 배치 크기: 64
- 기준 학습률: 0.001
- 기준 Epoch: 15
- 학습 시드: 42
- 2px 평가 데이터 시드: 2026
- 3px 평가 데이터 시드: 2027

## 6. 실험 구성

| 실험 | 변경한 조건 | 실제 실행 설정 |
| --- | --- | --- |
| 기준 | 기준 모델 | Epoch 15, 클래스당 400장, 학습률 0.001, 훈련 반지름 2px |
| A | Epoch 증가 | Epoch 30 |
| B | 훈련 데이터 증가 | 클래스당 800장, 총 6,400장 |
| C | 학습률 변경 | `0.001`에서 `0.0005`로 변경 |
| D | 점 크기 다양화 | 훈련 이미지마다 반지름 2px 또는 3px를 선택 |

모든 실험에서 학습 난수 시드를 42로 설정하고, 2px와 3px 평가 데이터는 각각 시드 2026, 2027로 생성해 같은 이미지로 비교했다.

## 7. 실험 결과

| 조건 | 2px 정확도 | 3px 정확도 |
| --- | ---: | ---: |
| 기준 | 92.3% | 17.5% |
| A: Epoch 30 | 92.5% | 17.0% |
| B: 클래스당 800장 | 98.6% | 15.5% |
| C: 학습률 0.0005 | 92.5% | 16.8% |
| D: 이미지마다 2px·3px 혼합 학습 | 92.6% | 90.0% |

## 8. 결과 분석

### 기준 모델

2px 이미지에서는 92.3%였지만, 3px 이미지에서는 17.5%였다. 점 크기가 달라지면 점 하나의 흰색 픽셀 면적도 함께 달라진다. 이번 실험만으로 모델이 점 개수와 점 크기 중 어떤 특징에 더 의존했는지는 구분할 수 없다.

점 개수별 정확도에서는 점 8개 이미지의 정답률이 63%로 가장 낮았다. 전체 정확도만 보면 어떤 개수의 이미지를 어려워하는지 알기 어려워 클래스별 결과도 함께 확인했다.

### 실험 A — Epoch 15에서 30으로

같은 평가 이미지로 비교했을 때 2px 정확도는 기준의 92.3%에서 92.5%로 0.2%p 높아졌고, 3px 정확도는 17.5%에서 17.0%로 비슷했다. 훈련 손실은 Epoch 30에서 0.0032까지 줄었지만 시험 정확도는 기준과 큰 차이가 나지 않았다.

점 8개 정답률도 63%에서 64%로 비슷했다. 오래 학습하면 훈련 오차는 줄 수 있지만 시험 성능이 크게 달라지지 않을 수 있다는 점을 확인했다.

### 실험 B — 클래스당 훈련 이미지 400장에서 800장으로

같은 평가 이미지로 비교했을 때 2px 정확도는 92.3%에서 98.6%로 높아졌다. 점 8개 정답률도 63%에서 91%로 높았다. 이번 실행에서는 훈련 이미지 수를 늘린 조건에서 더 높은 정확도가 관찰됐다.

반면 3px 정확도는 15.5%로 기준의 17.5%보다 낮았다. 훈련 이미지 수를 늘리는 것만으로 학습 데이터에 포함되지 않은 점 크기에 대한 성능까지 좋아지는 것은 아니었다.

### 실험 C — 학습률 0.001에서 0.0005로

2px 정확도는 92.5%, 3px 정확도는 16.8%였다. 기준의 92.3%, 17.5%와 비교하면 시험 정확도 차이는 크지 않았다.

학습률 0.0005를 사용한 실행은 마지막 Epoch의 훈련 손실이 기준보다 높았고, 시험 정확도는 학습 과정에서 오르내렸다. 이번 결과만으로 낮은 학습률이 더 좋다고 말하기는 어렵다. 손실 변화와 클래스별 정확도를 함께 살펴야 한다는 점을 배웠다.

### 실험 D — 훈련 이미지의 점 크기 혼합

훈련 이미지마다 반지름 2px 또는 3px를 선택해 학습한 결과, 2px 정확도는 92.6%, 3px 정확도는 90.0%였다. 기준과 같은 평가 이미지에서 비교했을 때 2px 정확도는 비슷했고, 3px 정확도는 높게 나타났다.

점 크기를 학습 데이터에 포함하면 크기가 달라진 이미지에 대응하는 데 도움이 될 가능성을 확인했다. 다만 한 번의 시드 결과이므로, 여러 시드에서도 비슷한 차이가 나타나는지 확인할 필요가 있다.

## 8. 한계 및 개선 방향

1. 이번 결과는 고정된 한 시드에서 실행한 값이므로, 여러 학습 시드로 반복해 평균과 변동 폭을 확인한다.
2. 학습 중 조건 비교에는 검증 데이터를 사용하고, 시험 데이터는 최종 모델을 정한 뒤 평가한다.
3. 점 위치와 크기 외의 이미지 특성도 바꿔 보며 어떤 변화가 모델 성능에 영향을 주는지 살펴본다.

각 실험은 학습 중에도 시험 정확도를 확인했다. 따라서 시험 결과를 보며 조건을 반복해서 선택하면 최종 성능 평가가 공정하지 않을 수 있다. 다음에는 검증 데이터로 조건을 비교하고 시험 데이터는 마지막에 평가하는 방식으로 나누고 싶다.

## 8. 배운 점

- 흑백 이미지를 숫자 배열로 만들고, PyTorch Tensor로 변환해 모델에 입력했다.
- `Flatten`으로 32×32 이미지를 1,024개 값으로 펼치고, MLP가 점 1~8개에 해당하는 8개 점수를 출력하도록 구성했다.
- `CrossEntropyLoss`로 예측 오차를 계산하고, 역전파와 Adam으로 모델 가중치를 업데이트하는 과정을 확인했다.
- 훈련 손실이 줄어도 시험 정확도가 같은 폭으로 좋아지는 것은 아니었다. 두 지표가 각각 무엇을 보여 주는지 구분해야 했다.
- 조건별 결과를 비교하려면 모델 설정뿐 아니라 평가 데이터도 같아야 한다는 점을 확인했다.
